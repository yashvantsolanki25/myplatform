Cloud Credentials

Amazon Web Services (EKS)Not set

Enter access keys, or leave them blank to use the app's AWS runtime identity. At least one region is required. Save verifies EKS access before storing credentials.

Google Cloud Platform (GKE)Not set

Paste a service account JSON key, or leave it blank to use the app's Google Application Default Credentials. Save verifies GKE access before storing credentials. Run gcloud iam service-accounts keys create to generate a key.

Microsoft Azure (AKS)Not set

Enter a service principal, or leave its fields blank to use the app's Azure runtime identity. A subscription ID is always required. Save verifies AKS access before storing credentials. Create a service principal with az ad sp create-for-rbac.
