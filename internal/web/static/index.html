Cloud Credentials

Configure your cloud credentials here. Changes apply immediately — no restart needed.

Amazon Web Services

Uses the AWS default credential chain (env vars, ~/.aws/credentials, SSO, instance profile). Set the regions to discover EKS clusters in.

ENV MYPLATFORM_AWS_REGIONS or AWS_REGION
Google Cloud Platform

Uses Application Default Credentials. Run gcloud auth application-default login first, then set your project ID.

ENV GOOGLE_CLOUD_PROJECT or GCP_PROJECT
Microsoft Azure

Uses DefaultAzureCredential (env vars, workload identity, az login). Set your subscription ID to discover AKS clusters.

ENV AZURE_SUBSCRIPTION_ID
